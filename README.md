# 🌿 Leaf Sage - Plant Disease Prediction Model

**Leaf Sage** is a machine learning-powered web application designed to detect plant diseases from leaf images. It leverages deep learning techniques to classify diseases based on visual symptoms, offering a quick and accessible tool for farmers, gardeners, and researchers to diagnose plant health.

## 🔍 Features

- Upload leaf images and get real-time disease predictions
- Simple and responsive interface using Streamlit
- Powered by a trained image classification model
- Easy to run locally with minimal setup

## 🚀 How to Run

1. **Clone the repository**

   ```bash
   git clone https://github.com/your-username/leaf-sage.git
   cd leaf-sage
2. **Install dependencies**
   
   pip install -r requirements.txt

3. **Run the app**

   streamlit run main.py
